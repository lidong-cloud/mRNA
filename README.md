# 转录组生信分析

一套针对GEO数据库进行生信分析的分析流程，主要包含数据整理、差异分析、富集分析、相关性分析及差异表达基因的可视化。

## 使用方法

1. 所有脚本均需要在 Linux 系统下运行。
2. 给脚本可执行权限：

   ```bash
   chmod 755 mRNA_DEG
3. 查看脚本帮助文档，哪些是脚本必须参数，哪些是可选参数，补全必须参数即可分析。
   
   ```bash
   mRNA_DEG --help
